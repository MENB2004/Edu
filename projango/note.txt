python virtual environment
1. Create a virtual environment:
   python -m venv venv

2. Activate the virtual environment:
   - Windows: venv\Scripts\activate
   - macOS/Linux: source venv/bin/activate

3. Install Django:
   pip install django

4. Create a new project:
   django-admin startproject project_name .

5. Change file:
   cd project_name

6. Run the development server:
   python manage.py runserver
   
7. Create a new app:
   python manage.py startapp app_name

8.Registering your app:
   - Open settings.py
   - Add 'app_name' to the INSTALLED_APPS list:
     INSTALLED_APPS = [
         ...
         'app_name',
     ]

9. Create a view:
   - Open app_name/views.py
   - Add the following code:
     from django.http import HttpResponse

     def index(request):
         return HttpResponse("Hello, world!")

10. Map the view to a URL:
    - Create a file named urls.py in the app_name directory
    - Add the following code:
      from django.urls import path
      from . import views

      urlpatterns = [
          path('', views.index, name='index'),
      ]

11. Include the app URLs in the project:
    - Open project_name/urls.py
    - Add the following code:
      from django.contrib import admin
      from django.urls import include, path

      urlpatterns = [
          path('app_name/', include('app_name.urls')),
          path('admin/', admin.site.urls),
      ]

12. Create a template:
    - Create a directory named 'templates' inside the app_name directory
    - Inside 'templates', create another directory named 'app_name'
    - Create a file named 'index.html' and add your HTML code

13. Update the view to use the template:
    - Open app_name/views.py
    - Modify the index function:
      from django.shortcuts import render

      def index(request):
          return render(request, 'app_name/index.html')

14. Database Migrations:
    - Create migrations for changes:
      python manage.py makemigrations
    - Apply migrations to the database:
      python manage.py migrate

15. Create a Superuser:
    - python manage.py createsuperuser
   

View:-

1.FBV:-  Function based View, Easy to understand, simple-intermediate functionality.
   - Open app_name/views.py
   - Add the following code:
     from django.shortcuts import render
     from .models import MyModel

     def my_view(request):
         data = MyModel.objects.all()
         return render(request, 'app_name/template.html', {'data': data})

2. CBV:- Class basef view, Not beginner friendly, complex-advanced functionality, suitable for enterprise level functionalities.


   - Open app_name/views.py
   - Add the following code:
     from django.views.generic import ListView
     from .models import MyModel

     class MyListView(ListView):
         model = MyModel
         template_name = 'app_name/template.html'
         context_object_name = 'data'


How to pull a Django project from GitHub?

1. Clone the repository:
   git clone <repository_url>

2. Navigate into the project directory:
   cd project_name

3. Create a virtual environment:
   python -m venv venv

4. Activate the virtual environment:
   - Windows: venv\Scripts\activate
   - macOS/Linux: source venv/bin/activate

5. Install dependencies:
   pip install -r requirements.txt

6. Apply database migrations:
   python manage.py migrate

7. Run the development server:
   python manage.py runserver

How to push a Django project to GitHub?

1. Create a .gitignore file:
   - Create a file named '.gitignore' in the root directory
   - Add common files to ignore:
     venv/
     *.pyc
     __pycache__/
     db.sqlite3
     .env

2. Create a requirements.txt file:
   pip freeze > requirements.txt

3. Initialize Git:
   git init

4. Add and Commit:
   git add .
   git commit -m "Initial commit"

5. Push to GitHub:
   git remote add origin <repository_url>
   git branch -M main
   git push -u origin main
